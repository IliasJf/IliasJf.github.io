# iliasjf.github.io

My portfolio: **[iliasjf.github.io](https://iliasjf.github.io/)**

I'm Ilias Jafaoui, a front-end developer in Morocco. I build fast, mobile-friendly websites and web apps for shops and small businesses. The site shows my skills, recent projects with live demos, the services I offer, my experience and how to contact me.

**Stack:** plain HTML, CSS and JavaScript, hosted on GitHub Pages. No build step: edit `index.html` or the files in `assets/` and push.
