# iliasjf.github.io

My portfolio: **[iliasjf.github.io](https://iliasjf.github.io/)**

I'm Ilias Jafaoui, a front-end developer in Morocco, open to remote work. I build stores, booking apps and dashboards in React, Next.js and TypeScript. The site shows my selected work with live demos, more projects, my experience, and how to reach me.

**Stack:** Next.js 16, TypeScript and Tailwind CSS 4, exported as a static site and served by GitHub Pages. All the text about projects and experience lives in `src/content.ts`.

## Run it

```bash
npm install
npm run dev     # http://localhost:3000
npm run build   # static site in out/, published to the gh-pages branch
```
